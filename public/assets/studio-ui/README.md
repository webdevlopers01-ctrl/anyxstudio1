# CLIENT.STUDIO Visual Asset Pack

This folder is reserved for the human-designed visual assets created in Canva for the studio website.

## Upload exports here

- backgrounds/hero-desktop.webp
- backgrounds/hero-mobile.webp
- backgrounds/services.webp
- backgrounds/shop.webp
- backgrounds/contact.webp
- backgrounds/about.webp
- services/broadcast-automation.webp
- services/gfx-design.webp
- services/other-services.webp
- portfolio/ (portfolio artwork / case-study images)
- motion/ (optional lightweight GIF/WebP animations)

## Rules
1. Prefer WebP for website images.
2. Use animated WebP/MP4/WebM for motion when possible; use GIF only when necessary.
3. Keep important subjects away from text-safe areas.
4. Do not use Canva editor links as website assets.
5. These are handoff assets only; the existing UI is not being changed in this phase.
6. After upload, the implementation pass will map each asset to the correct route/component.
